## About Subspace Continuum

[Subspace Continuum](https://store.steampowered.com/app/352700/Subspace_Continuum/) is a 2D massively-multiplayer online space-combat game from the late 1990s. Players pilot ships in shared *zones* — community-hosted servers where pilots fight, capture flags, race, and play custom game modes authored by mapmakers and module writers.

Each zone is owned and operated by its community. The game shipped without a central authority — a player-run universe.

## About Subspace Infinity

Subspace Infinity is a from-scratch Java reimplementation of both the Subspace client and server, built on the [JMonkeyEngine](https://jmonkeyengine.org/) game engine and the [Simsilica](https://github.com/Simsilica) ecosystem.

The goal: a faithful re-creation of the Subspace experience on a modern engine, with a modular, scriptable server architecture so zones, arenas, and game modes can be authored without forking the engine.

## Status

**Pre-alpha — single-maintainer project, no playable gameplay yet.**

The engine, networking, ECS, and configuration pipelines are under active development. Pre-alpha builds exist for early testing and feedback, but the core gameplay loop — ships, prizes, arenas, zone-vs-zone combat — is still being assembled.
